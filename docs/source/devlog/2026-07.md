# Development log - 2026-07

## 2026-07-31 - Main Agent Mode gained run-wide closeout

**Result**

- Main Agent Mode adopted a run-wide closeout capability as the normal handoff
  path, carrying terminal evidence across managed worker lifecycles.

**Why / context**

- Worker-local completion is not enough when one main agent owns acceptance,
  provider delivery, and cleanup for the whole run.

**Evidence**

- Commit `e38e2ee5` refreshed Codex and Claude acceptance goldens and closed the
  local run-wide closeout milestone.

**Links**

- [Implementation commit](https://github.com/sympoies/agent-runtime-kit/commit/e38e2ee5a7c65209580a29a9229f2af441b3bc69)

## 2026-07-22 - Main Agent Mode established managed ownership

**Result**

- A dedicated conversation workflow added doctor-gated ownership, verified
  worker handoff, admitted-operation recovery, and L2/L3 integration.

**Why / context**

- Parallel workers need one accountable conversation owner and provable
  lifecycle transitions without allowing coordination to expand authority.

**Evidence**

- Commit `85937f45` added the workflow, product exposure, rendered goldens, and
  acceptance coverage.

**Links**

- [Implementation commit](https://github.com/sympoies/agent-runtime-kit/commit/85937f45e68e2224ee3945de139514baa682ae8c)

## 2026-07-21 - Hook policy moved behind agent-hook

**Result**

- Runtime policy ingress moved from native provider registrations to a
  digest-pinned shared policy bundle installed by `agent-hook setup`.

**Why / context**

- One cutover and rollback owner prevents Codex and Claude hook ordering,
  migration, and policy behavior from drifting independently.

**Evidence**

- Commit `d98ac0b1` retained the legacy registration inventory, added conservative
  coordination rules, and tested migration, rollback, privacy, parity, and
  latency contracts.

**Links**

- [Implementation commit](https://github.com/sympoies/agent-runtime-kit/commit/d98ac0b18394ba0b2b5d29304824964acfa6ab0a)

**Result**

## 2026-07-18 - Home policy became an invariant and routing layer

**Result**

- `AGENT_HOME.md` was compacted into always-on invariants plus intent routing,
  with detailed requirements moved to intent cards and on-demand runbooks.

**Why / context**

- Prompt context is a runtime budget. Loading every detailed policy on every
  turn obscured the active contract and crowded out task evidence.

**Evidence**

- Commit `fadf017c` added the context-budget decision, neutral golden coverage, and
  product render checks while preserving safety-critical phrases.

**Links**

- [Implementation commit](https://github.com/sympoies/agent-runtime-kit/commit/fadf017ca4fec57369336f45fef1341d12e92226)
- [Intent cards](../../../core/policies/intent-cards.md)

## 2026-07-17 - Governed direct-main delivery was added

**Result**

- The runtime added a tightly scoped, signed one-commit direct-main exception
  while retaining pull requests as the default delivery route.

**Why / context**

- Rare local-default delivery needs explicit authorization, exact-base
  compare-and-swap evidence, and guard coverage rather than raw Git bypasses.

**Evidence**

- Commit `d7f12c78` bound delivery to the effective Git and shell context and added
  regressions for alias, refspec, wrapper, timeout, and nested-command bypasses.

**Links**

- [Implementation commit](https://github.com/sympoies/agent-runtime-kit/commit/d7f12c78814dc80684768b1a7a07f6348e1d3873)
- [Git delivery policy](../../../core/policies/git-delivery.md)
