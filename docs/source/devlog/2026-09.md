# Development log - 2026-09

## 2026-09-01 - Project devlog workflow established

**Result**

- The repository gained a monthly, newest-first development log, a literal
  search helper, a project-local `project-devlog` skill, and discoverable
  README and repository-policy entrypoints.
- The initial retained record curates implementation milestones from the
  repository bootstrap in May through the end of August 2026.

**Why / context**

- Commit, pull-request, plan, and policy history retain delivery detail but do
  not provide a compact narrative for later debugging. The devlog preserves
  why selected milestones mattered without becoming another current policy
  owner or exhaustive changelog.
- `docs/source/devlog/` follows the repository's canonical placement rule for
  durable repo-wide material.

**Evidence**

- The owner test was written before the new helper and initially failed because
  the executable did not exist. This is retained as setup evidence, with an
  explicit waiver because no predecessor behavior existed for meaningful red.
- Testing review then found a GNU-only grep option; a BSD-compatible shim test
  failed against that implementation before the helper moved to portable
  fixed-string arguments. Security review similarly drove failing owner cases
  before every success and error path stopped printing the machine-local
  checkout path. The three focused owner tests pass after both repairs.
- Independent maintainability, performance, and red-team review found no
  additional defects; testing and security follow-up review passed.
- Public first-parent history from May through August 2026 and release tags
  through `v2026.08.03` were reviewed to select the milestones below.
