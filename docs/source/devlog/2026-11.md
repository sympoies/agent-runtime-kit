## 2026-11-25 - Validate nils-cli v1.42.9 and accept the notice-only child config

### Result

- The validated nils-cli release moves from `v1.40.5` to `v1.42.9`; the
  compatibility minimum stays `v1.36.21`. Packaging digests, the Docker
  default, the surface snapshot, and the version mirrors move with it.
- The Codex-agent boundary fixtures now accept the notice-only `config.toml`
  that the private launch home carries, and still reject any other file.

### Why / context

- The fixtures expected only the auth bridge in the private child home. Since
  nils-cli `v1.42.1`, the launch also writes a config holding only the hidden
  rate-limit notice. The upstream execution-capsule spec and its own tests
  changed to expect that file, so the contract change is intended. Releases up
  to `v1.42.0`, including the minimum, write none, so the helper admits the file
  only when present and checks its exact content.
- The first failure appeared as soon as the host ran a current nils-cli; the
  pinned lane stayed green, which is why it surfaced only on ambient runs.

### Evidence

- The boundary layer passes on `v1.36.21`, `v1.41.10`, `v1.42.0`, `v1.42.1`,
  and `v1.42.9`; before the fixture change it failed on `v1.42.1` and later with
  the single-entry mismatch.
- The full canonical gate passes on the minimum, the previous validated
  release, and the new validated release.

### Links

- <https://github.com/sympoies/agent-runtime-kit/issues/434>
- <https://github.com/sympoies/nils-cli/pull/3935>

## 2026-11-14 - Protect private runtime state from audited text reads

### Result

- Enforced coordination rejects resolved private runtime text reads before the
  unauthenticated read lane, with a fixed diagnostic.

### Why / context

- Read-only shell effects do not imply confidentiality: file-content readers
  can disclose owner capabilities and retained execution proofs without
  mutating anything. Capability recovery and exact runtime diagnostics remain
  owned by the session runtime.

### Evidence

- Retained baseline red reproduced 234 private-read admissions in Codex and
  Claude. The regression matrix and existing missing-capability and
  read-grammar controls pass with the path guard. Designated security review
  exposed implicit recursive roots containing protected descendants; a second
  retained red run reproduced 12 admissions, and effective-root regression
  cases now pass for both products. A subsequent option-arity regression was
  reproduced with ten failures; explicit color and buffering options now
  preserve public reads while implicit private roots remain protected.
