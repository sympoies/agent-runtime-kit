# Development log - 2026-06

## 2026-06-30 - Hermes became a third product target

**Result**

- Render, install, doctor, skill listing, support matrix, and runtime sync were
  extended from Codex and Claude to Hermes.

**Why / context**

- A third adapter had to consume the same product-neutral source without
  changing the byte output of existing products or creating a separate policy
  implementation.

**Evidence**

- Commit `47b580c5` added Hermes manifests, schemas, target sources, goldens, version
  baseline, and harness-shape documentation while preserving Codex and Claude
  renders.

**Links**

- [Implementation commit](https://github.com/sympoies/agent-runtime-kit/commit/47b580c579991d771f53a6990cca777826315a8a)
- [Support matrix](../../../SUPPORT_MATRIX.md)

## 2026-06-24 - Shared memory entered Codex sessions

**Result**

- Codex gained a bounded once-per-session memory cue with status preservation,
  delimiting, and redaction.

**Why / context**

- Opportunistic personal context can improve continuity, but it must remain
  untrusted, bounded, and unable to change tool authority or hide failures.

**Evidence**

- Commit `a2c9d87e` added the hook, managed-block registration, runtime documentation,
  and regression coverage.

**Links**

- [Implementation commit](https://github.com/sympoies/agent-runtime-kit/commit/a2c9d87ee1a22f21a721c60d08a59c9ec74801b7)

## 2026-06-21 - Review outcomes moved through forge-cli

**Result**

- Delivery and dispatch review workflows began publishing governed reviewer
  outcomes through `forge-cli` and bot profiles.

**Why / context**

- Provider identity, schema, and publication behavior need one controlled
  boundary instead of raw provider comments from individual skills.

**Evidence**

- Commit `b7294421` adopted the released review primitive, updated skill floors, and
  refreshed runtime-smoke coverage and rendered goldens.

**Links**

- [Implementation commit](https://github.com/sympoies/agent-runtime-kit/commit/b7294421c56aaebbb48907b73844d77d5336bfe9)

## 2026-06-20 - Codex adopted the plugin marketplace surface

**Result**

- Codex gained a gated plugin marketplace, symlink-free state-home
  materialization, and explicit activation through runtime sync.

**Why / context**

- Plugin discovery needed to match the product's native surface while keeping
  activation dry-run-first and avoiding duplicate flat-skill exposure.

**Evidence**

**Links**

## 2026-06-14 - Code review moved to specialist subagents

**Result**

- The shared review workflow gained one quick reviewer and seven read-only
  specialist profiles rendered for Codex and Claude.

**Why / context**

- Review depth should follow risk while the parent agent retains scope,
  synthesis, repair, provider, and merge ownership.

**Evidence**

  runtime smoke, rendered goldens, and pre-merge routing.
