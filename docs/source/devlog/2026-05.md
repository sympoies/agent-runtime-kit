  project validation command after edits and before session completion.

**Why / context**

## 2026-05-29 - Private skills gained a safe overlay

**Result**

- A dry-run-first overlay exposed project-local private skills to Codex and
  Claude without committing them or placing them in the governed catalog.

**Why / context**

- Personal skills need a separate source boundary and must not be mistaken for
  portable runtime-kit content or overwrite foreign runtime paths.

**Evidence**

- Commit `7b991d32` added no-clobber symlink ownership, prune behavior, and a safe no-op
  when the private source root is absent.

**Links**

- [Implementation commit](https://github.com/sympoies/agent-runtime-kit/commit/7b991d3272e1e0d81142cc8bb238e94e951f7686)
- [Private skill setup](../../../DEVELOPMENT.md#overlaying-private-skills)
