# Work Tier Levels (superseded)

The numbered tier ladder is replaced by the named work modes in
[`work-modes.md`](work-modes.md). That file owns mode selection, the program
workflow, the cross-cutting delivery rules, and the `docs/discussions/` capture
lifecycle. No policy or skill in this repository reads this path any more; it
is kept only so that existing external links still resolve, and it carries
nothing beyond the legacy mapping below.

| Legacy | Mode |
| --- | --- |
| `L0` | `direct` |
| `L1` | `issue` |
| `L2` | `program/plan` |
| `L3` | `program/dispatch` |
