# Work Tier Levels (superseded)

The numbered tier ladder is replaced by the named work modes in
[`work-modes.md`](work-modes.md). That file now owns mode selection, the
program workflow, the cross-cutting delivery rules, and the
`docs/discussions/` capture lifecycle. This path remains only until every
caller has migrated to the new file.

| Legacy | Mode |
| --- | --- |
| `L0` | `direct` |
| `L1` | `issue` |
| `L2` | `program/plan` |
| `L3` | `program/dispatch` |
